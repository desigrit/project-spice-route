Update Spice Route on all your devices before your next Push. Version 1.7 writes a new handoff format and can still read older handoffs.

- Pull checks the receiving Codex runtime before downloading project files. If a chat requires a newer runtime, the message identifies the chat and tells you which device to update.
- Push can publish while the other computer is offline. Spice Route recognizes ordinary new indexes and safely handles supported nullable fields. Reviewed rules for new device-local tables can arrive independently of an app release.
- Codex database layout 64/9 is supported, including attached chats and the stable aliases Codex uses when continuing a session.

On Spice Route 1.6.8 or later, choose **Settings > Updates > Check for updates**, then **Install and restart**.
